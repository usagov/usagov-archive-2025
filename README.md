# usagov-archive-2025

USA.gov static site archive

This repo archives the files served from USA.gov. The directory structure does not match the URL paths of the site; a web server described by https://github.com/usagov/usagov-2021/blob/dev/.docker/Dockerfile-www (with related configuration in the same repo) handles requests and proxies the "index.html" files, for example, at their parent paths.
